# Cactus Repair — мод для Minecraft 1.21.7 (Fabric)

## Что делает
1. **Кактус чинит предметы.** Кинь на кактус любой предмет с прочностью (инструмент, броню, лук, щит и т.д.) — вместо уничтожения он мгновенно чинится до 100%. Подбери — и готово. Предметы без прочности кактус уничтожает как обычно.
2. **Голем-фермер.** Ударь железного голема **голой рукой** (пустая основная рука) — из него выпадет 1 железный слиток за каждый удар. С предметом в руке слитки не падают.

## Как собрать
Нужны: **JDK 21** и **Gradle 8.10+** (или IntelliJ IDEA, она сама всё подтянет).

```bash
cd cactus-repair
gradle build
```

Готовый jar появится в `build/libs/cactus-repair-1.0.0.jar`
(файл `-sources.jar` устанавливать не нужно).

## Как установить
1. Установи **Fabric Loader** для 1.21.7 (https://fabricmc.net/use/installer/).
2. Скачай **Fabric API** для 1.21.7 (https://modrinth.com/mod/fabric-api) и положи в папку `mods`.
3. Положи туда же собранный `cactus-repair-1.0.0.jar`.

## Если сборка ругается на версии
Версии yarn/loader/fabric-api в `gradle.properties` могли обновиться —
актуальные значения для 1.21.7 смотри на https://fabricmc.net/develop/
и просто подставь их в `gradle.properties`.
